# 英语单词小词典

一个优先为手机课堂使用设计的离线英语词典：可以快速输入中英文、从课本照片提取标记词、自动生成单词卡片，并按日期选择历史单词进行即时练习。

## 按日期速练

- **海怪速击**：根据中文意思和音节拼写英文，输入正确即可击退海怪。
- **句子拼读**：把刚录入的生词填回短句，答对后自动朗读完整句子。
- 每个句子中的生词最多可以提示 3 次，每次多显示 1–2 个字母。
- 连续答错或选择“暂时不会”的单词，会自动排到本轮末尾再练一次。
- 游戏使用所选日期的全部单词；新批次排在旧批次前，每批内部顺序不变，重复词保留。
- 完整英文短语会优先查询本地短语词条，不再被当作单个单词或直接判定为查不到。

## 数据与离线使用

- 单词卡片和练习记录只保存在当前浏览器中。
- 网站不会上传课本照片；拍照识别在设备本地完成。
- 第一次打开和第一次拍照识别需要加载离线词典及识别组件，之后会由浏览器缓存。

## GitHub Pages

项目是纯静态网站，可直接从仓库根目录发布。`index.html` 是词典首页，`.nojekyll` 用于让 GitHub Pages 原样发布资源目录。
